# 🥋 Codewars Solutions in Python

Este repositorio recopila mis soluciones en **Python** para los katas de [Codewars](https://www.codewars.com/), abarcando desde fundamentos hasta niveles avanzados (Kyu 4).

El propósito de este espacio es demostrar constancia en la práctica algorítmica, la optimización de código limpio y la resolución de problemas lógicos bajo restricciones de rendimiento.

---

## 📊 Progreso por Niveles (Kyu)

* **Kyu 4:** Algoritmos avanzados, estructuras de datos complejas y optimización de rendimiento.
* **Kyu 5 / Kyu 6:** Lógica intermedia, manipulación de colecciones y algoritmos de búsqueda.
* **Kyu 7 / Kyu 8:** Fundamentos y agilidad en la sintaxis de Python.
